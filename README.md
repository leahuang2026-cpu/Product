# Personal OS

Personal OS 是个人知识与人生档案产品。通过 Memory、Focus 和 Direction 连接已保存的材料、当前重点和长远方向。首批验证文字与图片录入、手机和电脑上的私人找回，以及当前关注与下一步。

**接手项目先读 [PROJECT_STATUS.md](PROJECT_STATUS.md)**，再按任务阅读对应文档。

| 文件 | 用途 |
|---|---|
| [PROJECT_STATUS.md](PROJECT_STATUS.md) | 当前阶段、文档版本、待决项和下一步 |
| [AGENTS.md](AGENTS.md) | AI 协作、开发范围与交付规则 |
| [docs/PRD.md](docs/PRD.md) | PRD V1.0，区分已确认边界、拟定设计和待决项 |
| [docs/DECISIONS.md](docs/DECISIONS.md) | 已确认决定、待决项及历史依据 |
| [docs/TASKS.md](docs/TASKS.md) | 任务顺序、责任和验收依据 |
| [docs/CHANGELOG.md](docs/CHANGELOG.md) | 已交付的文档及后续产品变更 |
| [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md) | 测试、证据和产品验收状态 |

Chat 负责讨论与决策整理，Work 负责交付与验收协调，Codex 负责实现与测试。跨对话交接通过上述文档和 Git 提交完成。对话负责讨论过程，正式版本以仓库和用户确认记录为依据。

`src/` 是应用源码的预留目录。仓库为公开可见，开发样本使用虚构或脱敏内容。
