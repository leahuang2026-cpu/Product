## 信息架构

| 路由          | 页面          | 关键交互                                                         |
| ------------- | ------------- | ---------------------------------------------------------------- |
| `/`           | 我的空间      | 过去/现在/未来摘要、快捷记录、当前关注、近期记录、花园与复盘入口 |
| `/capture`    | Quick Capture | 文字/音频文件/图片/链接切换，领域与标签，保存提示                |
| `/archive`    | Archive       | 搜索标题、原文、标签，五领域筛选，详情对话框                     |
| `/focus`      | Focus         | 新建阶段重点、可选关联方向、添加和勾选行动                       |
| `/direction`  | Direction     | 新建方向、查看原因与时间视野、演示建议确认/拒绝                  |
| `/ideas`      | Idea Garden   | 新建灵感、状态过滤、暂停/探索/激活                               |
| `/reflection` | Reflection    | 周/月切换、三问填写、历史折叠查看                                |
| `/settings`   | 数据与设置    | 导出、校验导入、清空、示例恢复、原始备份                         |

桌面采用固定侧栏+内容区；手机使用顶部菜单及覆盖导航。表单按钮可通过键盘访问；对话框使用原生 dialog（焦点约束、Escape 关闭）；导航标注当前页面，提供跳转主内容入口。加载、空结果、异常、成功反馈均有对应状态。

## 有意保留的体验边界

- 链接仅收藏，不自动抓取外部数据；打开链接在新标签页并使用 noopener/noreferrer。
- 语音入口当前接受已有音频文件，录音与转写留待后续。
- 灵感激活只是状态变化，项目创建始终由用户主动触发。
- 复盘保存原文，不自动给用户打分或调整目标。
- 页面直接显示当前数据；首页没有虚构的完成率、签到、积分或成就。
- 默认示例用于展示布局与流程；设置页可确认清空后体验真实空状态。

## 与补充需求的差距（计划中）

- 首页的当前关注来自 `projects.slice(0, 2)`，不是用户主动排序；只显示项目标题和下一行动，不显示其关联 Goal。
- `/focus` 显示项目关联方向，但阶段重点与项目仍共用 Project 对象，尚未达到 FOC-01 的概念区分。
- 未来信息层次为长期方向、当前阶段重点、项目、行动、独立灵感；具体关系和基数待 Q-01/02 确认。
- 记录处理意图、灵感演变历史、引用式复盘和作品管理尚无完整入口。

上述是需求差距，不代表本轮新增页面或调整交互。路由是否拆分，应在语义确认后决定。
