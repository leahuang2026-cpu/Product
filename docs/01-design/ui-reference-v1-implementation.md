## 参考与已确认规则的区别

- 参考中的四项导航适配为现有五模块：关注/Focus、档案/Archive、方向/Direction、灵感/Idea Garden、复盘/Reflection；只是显示名称调整，现有路由保持。采集保留在顶部入口、首页及独立页面。
- 领域继续多选、任一匹配；不采用参考中较早的单选提示。全局领域过滤器放在对应模块标题后，档案中放在搜索框后；筛选状态仍跨模块保留。
- Focus 关联和下一步继续可空，不增加参考中的独立“项目”实体或数量限制。
- 不把示例资料写入应用。首页最近记录来自现有本人 API，并遵循当前领域筛选；读取中、错误、空列表分开显示。图片缩略图仍使用已鉴权内容路径，不生成公开原图链接。
- 保留保存重试、原文不覆盖、失败留输入、显式分类保存、灵感取消保留原文、回收站移入/恢复、退出与本人权限。新品牌栏、最近记录和底部导航都经过未保存输入保护。

本轮没有 SQL、数据模型、API、RLS、Storage 权限或环境变量修改，没有导入旧数据，也没有把 AI、转写、抓取或恢复写入当作视觉改版的一部分。
