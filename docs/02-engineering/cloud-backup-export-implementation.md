## 1. 已实现与可见行为

设置页新增“云端档案备份”，不增加导航模块。勾选未加密及包含回收站说明后生成；接收完毕且本地校验通过才出现“保存备份文件”。用户点击保存后由浏览器处理落盘，页面不承诺已保存到某个目录。文件可再次选择，在 Web Worker 内离线校验，不上传云端或 AI；可取消、清除、失败后重试。退出登录或离开设置会销毁待下载链接和校验状态，不承诺草稿/下载任务跨刷新持久化。

范围包括全部 records、已绑定原件、Focus（含 inactive）、Direction、Reflection，保留原文空白、微秒时间字符串、领域、灵感、附件顺序、关系和回收站标记。未保存草稿、旧 localStorage、未绑定上传、账号/密钥/服务配置与请求缓存不在范围；不会删除这些内容。没有新增恢复写入按钮。

普通列表和附件详情仍隐藏回收站；导出使用独立本人只读快照，既有 RLS、原件保护、Storage 私有策略及不可删除授权不变。

## 2. 文件和 API 合同

- `POST /api/backups/export`：同源请求、本人会话、reviewed-v2 开关；调用 `personal_os_backup_snapshot_v1()`。没有用户传入的 owner/path/筛选参数，不使用 service-role。
- SQL 是 `STABLE SECURITY INVOKER`；单次调用的所有查询共享语句快照，统计/读取不拼接分页，所以超过 1,000 条不漏导出。只新增函数及它的 authenticated 执行权限；匿名/PUBLIC 不可执行，不改表或 Storage 权限。
- 结构化快照仅返回白名单列；未知表列或 entry 字段阻止导出，避免默默丢数据。快照包含未删除/回收站条目及完整附件元数据。
- Next.js 从当前会话的私有存储按 `本人 UUID/附件 UUID` 读取原件；逐个限量接收并比对长度/SHA-256，不读取用户指定路径、不重编码原件。任何原件失败都会中断流，不发完成清单和 ZIP 结束目录；客户端也不提供残包下载链接。
- ZIP 使用精确锁定的 `fflate@0.8.3` 流式 STORE 写入。JSON/README/原件先写、manifest 最后写；服务端逐个文件读取并受消费速度控制。不会在 Render 磁盘或公开 bucket 保存 ZIP。
- 客户端为兼容浏览器，当前使用有上限的 Blob 接收，完成后 Web Worker 校验，再通过显式下载链接保存。不是浏览器直接流式写磁盘；其内存边界与 iOS 文件体验必须如实验证。
- 校验器只接受本应用 formatVersion=1 的未压缩普通 ZIP 子集。检查中央目录、本地头、STORE 方法、CRC32、重复/危险路径、符号链接属性、分卷/加密标志、大小边界、清单 SHA-256、严格 JSON 字段、计数和引用。不会解压运行内容，也不支持用户重新压缩或加密的包；SHA-256 不提供来源认证或保密性。
- 不同 ID 所属表独立；导出包含原始 sourceVersion，未来恢复仍不得把它当作覆盖权限。环等未来恢复不支持的关系，不在本轮擅自修复。
- 响应 `private, no-store` / `Vary: Cookie`；错误不返回私人原文或底层数据库详情。单进程一次生成，120 秒操作上限；不是跨实例持久任务或续传保障。

## 3. 实测与当前工程上限
