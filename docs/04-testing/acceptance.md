## 自动化命令

| 命令                | 范围                                                                             |
| ------------------- | -------------------------------------------------------------------------------- |
| `npm run lint`      | ESLint、React/Next 规则                                                          |
| `npm run typecheck` | TypeScript strict                                                                |
| `npm test`          | 7 个领域测试：原文空白保留、备份往返、建议确认/拒绝、筛选、坏数据与危险 URL/附件 |
| `npm run db:check`  | 官方 Prisma WASM 解析及 13 个模型关系验证，无需原生引擎/数据库                   |
| `npm run build`     | 生产编译、类型检查与路由预渲染                                                   |
| `npm run test:e2e`  | Chromium 桌面和 Pixel 7 视口上的真实浏览器交互                                   |

E2E 共 12 个场景 × 2 个视口 = 24 个测试。每个测试独立浏览器上下文，验证全部路由无横向溢出、记录保存刷新、领域筛选与详情、灵感状态、目标建议确认、复盘历史、无效导入与清空确认。并发限制为 2，自动启动生产服务；先运行 build。

## 人工验收清单（待执行；不等于用户验收已通过）

1. 首页点击保存，内容留存在 Archive；刷新后可再次搜索到，换行和原文一致。
2. 完整 Capture 添加 HTTP(S) 链接和标签；javascript/data 链接不可保存。
3. 图片/音频选择受支持的 ≤1 MB 文件，保存后可查看/播放/下载；大文件被拒绝并提示。
4. Focus 新建项目，选择已有方向，添加行动并勾选；刷新后状态一致。
5. Direction 查看演示建议后取消，原标题保持；确认后标题改变且建议不重复出现。
6. Idea Garden 新增灵感，暂停/激活，Focus 不会产生额外项目。
7. Reflection 周度与月度均可填写三问，保存后从历史展开全文。
8. Settings 导出完整 JSON；导入需要覆盖确认，恢复记录与关联；非法文件不改变数据。
9. 导出备份后测试清空、取消清空、载入示例；空状态可继续新增记录。
10. 手机视口无横向滚动，导航可打开/关闭，键盘可进入表单、关闭对话框。
11. 模拟 localStorage 配额耗尽时，保存显示失败且保留输入；损坏 JSON 不被启动过程自动覆盖。

## 范围与限制

本地持久化和领域测试不等价于数据库集成测试。PostgreSQL 迁移、认证隔离、对象存储、真实 AI、真实移动设备麦克风与编码兼容性仍待后续验证。浏览器测试使用 Chromium 的桌面/手机视口，尚未覆盖 Safari 和 Firefox。

本轮实际执行结果见 [核查报告](verification-2026-11-05.md)，覆盖边界见 [测试用例](test-cases.md)。测试源码与配置在工作区，当前尚无 Git 提交。
