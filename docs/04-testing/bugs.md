## BUG-REF-001｜月度复盘新建默认周度，保存后列表未跟随周期

- 日期：2026-11-08（Asia/Shanghai）。来源：Owner 实际使用反馈。
- 现象：月度页签新建保存后内容出现在周度，月度仍为空。
- 定位：EntryEditor 新建 cadence 固定 weekly；EntriesView 的 period 未传入表单，也未在保存成功后同步为保存结果周期。API/SQL 保留 payload.cadence，源码未发现服务端强制转周度。未读取用户实际记录，不能断言每条受影响内容的存储值。
- 修复：新建默认跟随当前页签；编辑保留既有 cadence；保存成功后列表切换到返回结果的周期。仅改 UI，不改数据库/既有记录。
- 验证：新增四宽度浏览器回归，覆盖月度默认、表单改周期、编辑改周期、周月隔离及刷新后重新选月可找回。实际运行四宽度全部 52 项通过（含新增 4 项周期回归），生产 build、13 项单元、lint、typecheck 通过。合成 API 测试不代表实际云端已复验。
- 既有数据：不自动搬移；Owner 可查看周度中的测试复盘，确认意图后在编辑表单将周期改为月度。
- 状态：本地修复及回归通过，Render 部署/Owner 复验待完成。

BUG-REF-001 后续：Owner 反馈自动部署后月度新建默认、周/月列表隔离、刷新找回“都正常”；用户复验通过。
