# Personal OS｜测试用例与覆盖矩阵

> 用途：把实际断言与需求对应，记录尚未执行的验收场景。
> 状态：既有用例本轮已测试；新需求用例计划中；用户验收待确认。
> 更新：2026-11-06（Asia/Shanghai）。
> 结果来源：[本轮核查报告](verification-2026-11-05.md)。

## 执行约定

只用合成记录与 Playwright 独立 browser context，不载入用户真实浏览器档案。导入、清空、配额异常仅发生在测试上下文。`npm run build` 后执行 E2E，`CI=1` 防止复用未知服务；测试进程自行启动并结束自己的服务器。测试数据不作为用户反馈引用。

## 领域测试（7 个）

源码：[domain.test.ts](../../tests/domain.test.ts)。以下 7 项本轮均通过。

| ID    | 输入 / 操作                                   | 期望断言                                                  | 需求           |
| ----- | --------------------------------------------- | --------------------------------------------------------- | -------------- |
| UT-01 | 带首尾空白/换行的原文与纯空白文本             | 有效原文原样保留；纯空白拒绝                              | CAP-02         |
| UT-02 | 示例完整状态导出再导入                        | 深度相等，含关联和建议状态                                | DATA-02        |
| UT-03 | 未确认接受提案、确认接受、重复接受            | 未确认/重复拒绝，确认修改标题并记录状态，原对象与原文不改 | AI-03          |
| UT-04 | 拒绝目标建议                                  | 原目标内容保持                                            | AI-03          |
| UT-05 | 查询原文/标题/标签并叠加领域                  | 返回预期记录集合                                          | ARC-01         |
| UT-06 | 未知版本、孤立 goalId、重复顶层记录 ID        | 导入校验拒绝                                              | DATA-02        |
| UT-07 | javascript/data URL、不匹配媒体 MIME 或缺附件 | 不接受危险协议或无效结构；合法 HTTPS 接受                 | CAP-01/DATA-01 |

不把 UT-07 等同完整安全审计，或把 UT-06 等同所有数据约束已覆盖。

源码：[workspace.spec.ts](../../tests/e2e/workspace.spec.ts)、[data.spec.ts](../../tests/e2e/data.spec.ts)。共 24 次测试，本轮均通过。

| ID     | 准备与操作                                                                    | 预期 / 实际断言边界                                              | 需求                        |
| ------ | ----------------------------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------- |

| E2E-03 | 新建灵感→暂停→刷新→激活→Focus                                                 | 暂停持久化，激活不增加项目数量                                   | IDEA-01                     |
| E2E-04 | 查看建议→取消→再次查看并确认→刷新                                             | 取消不变更，确认后的标题持久化，提案不重复显示                   | AI-03                       |

| E2E-08 | 下载 JSON→清空→导入该 JSON→确认→刷新                                          | 导出内容有效，导入后完整状态与备份相等                           | DATA-02                     |
| E2E-09 | 新建方向→新建并关联项目→新增行动→勾选→刷新                                    | 关联标题和行动状态持久化                                         | DIR-01，FOC-01 的已实现部分 |

| E2E-12 | 从首页打开导航，点击灵感花园（手机先打开菜单）                                | 到达 Ideas，标题正确；**不包含从花园返回首页的断言**             | UX-01                       |
