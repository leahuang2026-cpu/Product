## 范围

第一阶段工程已提供浏览器本地可运行框架。本轮仅建设文档与核查现状，不开发下表尚缺的功能，不改变个人数据，不部署。后续优先级为建议，重大产品变更由用户确认。

## 核心概念

| 概念                 | 产品含义                                   | 当前实现                                    |
| -------------------- | ------------------------------------------ | ------------------------------------------- |
| Memory / Archive     | 经历、知识、问题、原文及整理结果的长期沉淀 | 本地记录和检索；AI/关联能力不完整           |
| Direction / 长期目标 | 用户自主选择的长期方向及理由               | Goal 对象与方向页面                         |
| 当前阶段重点         | 这个阶段主动选择的关注事项，应与项目区分   | 尚无独立对象；现页面将 Project 称作阶段重点 |
| 进行中项目           | 围绕具体成果展开的工作                     | Project，可关联 Goal                        |
| 具体任务/行动        | 项目下的下一步                             | Action，现嵌入 Project                      |
| 暂存灵感             | 可以持续收藏、探索、暂停的可能性           | Idea，现有四种状态                          |
| Reflection           | 基于真实历史的周/月回顾                    | 手写三问；未实现历史引用和 AI 复盘          |

## 目标体验约束

1. 用户可不选择 AI 服务而完成记录、查看与导出；不得把日志默认送交 AI 评价。
2. 记录的输入类型和处理意图区分；“发展为作品”不等于公开，“留待复盘”不等于创建任务。
3. 灵感转项目只能由用户主动执行；不能用“激活”暗示自动转化。归档不等于删除。
4. 首页对当前关注与方向展示明确关系；未关联时的表达方式待确认，不能推断一个用户未选的目标。
5. AI 结论必须区分引用事实与建议；找不到依据时说明缺失，不补造经历。
6. 数据覆盖与破坏性操作需明确对象、后果和用户确认；开发测试不得触及用户真实数据。

## 非目标与验收

本轮不新增业务、第三方同步、原生桌面组件、真实 AI 或部署，不以商业化指标排期。未来使用场景不等于本轮开发授权。

功能验收见[验收标准](../04-testing/acceptance.md)。用户是否认可真实体验、是否满足个人需求以及可接受的效率/负担，均「待确认」。尚无正式用户验收结论。
