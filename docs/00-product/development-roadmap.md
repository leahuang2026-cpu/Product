## 进入实施的门槛

用户上传的是 PRD V1.0 **评审稿**，不是全部拟定项的批准。先确认分类（O02）、Focus 最小关系/数量、数据编辑/保留（O03/D15）、账户和预算/区域（O04）。F10 按“仅保存”规划基线，不把提字、摘要、推荐分类自动纳入。

原计划“先关注闭环”的建议留存历史。D13 已明确云同步，建议先复用原型完成文字/图片的保存后分类流程设计，再以认证和持久化支撑第一条真实文字链路，随后图片与 Focus。纯本地 UI 可并行准备，但不能称为首批云版本完成。

## 首先开发什么

正式 PRD 和 T02 范围通过后，建议首先交付 **T03 + T04：本人登录后的云端文字记录闭环**，让文字确实能保存、可选分类并在另一设备重新打开。随后 T05 验证原图权限和可靠上传，再完成 T07 的首页 Focus；原型已有页面足够复用，不需要再次搭建项目。

用户也可选择先验证完整文字/图片 UI 再接云；这只是原型验收步骤，不能代替 F07/A02/A10/A11 的上线条件。任何付费资源、生产部署或真实数据迁移需另获相应授权。
